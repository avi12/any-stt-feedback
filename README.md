# AnySTT — Feedback

[![Get it from Microsoft Store](https://img.shields.io/badge/Microsoft%20Store-Get%20AnySTT-0067b8?logo=microsoftstore&logoColor=white)](https://apps.microsoft.com/detail/9P53HPP0KFLX)

**AnySTT** brings multilingual voice typing to Windows' own **Win + H** panel — dictate in any language your keyboard types, not only the few Windows ships a speech model for.

This repository is where that feedback lives. There's **no source code here** — just a place to tell us what works and what doesn't.

## Get AnySTT

Install it from the Microsoft Store:

**https://apps.microsoft.com/detail/9P53HPP0KFLX**

## Report a bug or request a feature

[**Open an issue**](https://github.com/avi12/any-stt-feedback/issues/new/choose), and include what helps us reproduce it:

- Your **Windows version** — Settings → System → About → *OS build*
- The **keyboard language** you were dictating in
- The **recognizer** picked in Win + H's gear menu (Copilot / Google Speech Recognition)
- What you expected, and what happened instead

## Questions

Not sure it's a bug? Open an issue anyway — questions are welcome.
